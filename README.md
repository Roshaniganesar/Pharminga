Pharminga – Pharmacy Inventory Management System

About

Pharminga is a web-based Pharmacy Inventory Management System designed to help manage pharmacy inventory and improve operational efficiency.

Features

- Pharmacy inventory management
- Medicine information
- User management
- Return management
- Compliance management
- Reporting and analytics
- User-friendly interface

Technologies Used

- HTML
- CSS
- JavaScript


Purpose

This project was developed for educational purposes to demonstrate a basic pharmacy inventory management system.
